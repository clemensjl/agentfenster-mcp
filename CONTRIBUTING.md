# Contributing

This repository holds the public documentation and the issue tracker for the agentfenster MCP server. The product itself is closed source, so there is no code to contribute here.

## Issues

Use the issue tracker for:

- bugs in tool behaviour (a click reported as successful that did nothing, a wrong element tree, a failed verification)
- install problems with `agentfenster-mcp`
- compatibility problems with an MCP client

Include the agentfenster version, the Windows version, the MCP client you use and the exact tool call with its output. Remove personal data and anything you would not post publicly. Questions about the app itself are answered faster on [Discord](https://discord.gg/J9MfKP255Y) or at <hello@agentfenster.com>.

## Documentation fixes

Typos, wrong tool descriptions and outdated requirements can be fixed with a pull request against `main`:

1. Fork the repository and branch from `main`.
2. Edit `README.md`. Keep the text factual and short.
3. Open a pull request and say what was wrong and where you checked it.

By contributing text you agree that it is published under the [CC BY 4.0](LICENSE) license of this repository.
